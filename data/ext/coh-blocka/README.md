# data/ext/coh-blocka

Coherence paper, human study Block A: every version of every edit pair, as an item to be mined in one run (`zsh scripts/run_ext_mined.sh coh-blocka 8 graph_gpt6`). Ids are `cba-<pair>-<version>`; which version is which is in the answer key. 160 items. Built by `scripts/coherence_study_build.py --seed 20261128`.
