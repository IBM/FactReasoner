# data/ext/loco-nonseq

Coherence paper, non-sequitur control (third review, N16; 2026-11-28). For each increasing LoCoBench test family's rung-0 response, a sentence "That <conclusion> follows from the fact that <premise>." is inserted directly after the conclusion's sentence, naming both claims. `nonseq`: the unlinked pair of true claims with the least word overlap, from different paragraphs. `valid` (CHAIN families): an entailment the ladder's top rung adds, stated in rung 0 with the same template (positive control). Claims are unchanged; the unedited responses (`nsq0-`) are mined in the same run. 146 families, 332 items. Built by `scripts/ext_build_nonseq.py`.
