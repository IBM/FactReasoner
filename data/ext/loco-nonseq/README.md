# data/ext/loco-nonseq

Coherence paper, second review, Phase C4 (2026-11-28): a non-sequitur control. For each increasing LoCoBench test family's rung-0 response, one sentence asserting that a true claim follows from another, unrelated true claim (no gold relation, different paragraphs, least word overlap) is appended to the conclusion's paragraph; claims are unchanged. The unedited responses are included (`nsq0-` ids) and mined in the same run. 360 items. Built by `scripts/ext_build_nonseq.py`.
