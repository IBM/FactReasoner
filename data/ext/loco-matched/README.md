# data/ext/loco-matched

Coherence paper, second review, Phase C (2026-11-28): LoCoBench rung-0 originals and their two paragraph permutations from loco-shuffle. Each original and permutation is copied twice (ids suffixed `__r1`, `__r2`) and the items are shuffled, so repeats and permutations are mined, and judged, in one interleaved run. 180 documents, 1080 items. Built by `scripts/ext_build_matched.py`.
