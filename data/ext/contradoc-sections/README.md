# data/ext/contradoc-sections

Coherence paper, second review, Phase C (2026-11-28): ContraDoc clean Wikipedia documents with >= 3 headed sections; whole headed sections permuted, title and lead first, headers kept with their sections and not claims; stories excluded. Each original and permutation is copied twice (ids suffixed `__r1`, `__r2`) and the items are shuffled, so repeats and permutations are mined, and judged, in one interleaved run. 129 documents, 774 items. Built by `scripts/ext_build_matched.py`.
