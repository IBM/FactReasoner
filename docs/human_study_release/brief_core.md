# Annotator brief: core session

Thank you for taking part. This session takes **about 2 hours 45 minutes**, and never
more than 3 hours. Take the 10-minute break after your fourth family. Please read this
whole brief before you start. It is short, and the task is easy to get wrong by accident.

## What you will do

Each task is one **response**: a few paragraphs answering a question about a real field
(engineering, history, medicine and so on). You will see 9 or 10 of them, plus one
practice task first.

For each response you do three things, in order, all on one screen:

1. **Read the response once, carefully.** Its claims are numbered underneath it.
2. **Part 1: claim pairs.** About 15 pairs of numbered claims.
3. **Part 2: claims as stated.** Every numbered claim, one at a time.
4. **Part 3: edited versions.** A few versions of the same response, each with a change
   marked.

Every question is about the response you just read. You do not need any outside
knowledge, and you should not look anything up.

## Part 1: claim pairs

For each pair, answer three questions.

**Does the response draw a logical link between these two claims?** A link means the
text connects them: one causes, supports, explains, restates, contrasts with, or rules
out the other. Two claims that simply appear in the same response, with no connection
drawn, are **not linked**. Mentioning the same topic is not a link.

**Could both claims be true at the same time?**
**Could both claims be false at the same time?**

Answer these two from the **meaning of the claims themselves**, not from the response
and not from what you know about the world. Imagine you knew nothing else. For example:

| Claim X | Claim Y | Both true? | Both false? |
|---|---|---|---|
| The bridge was built in 1920. | The bridge was built in 1935. | No | Yes |
| The fire started in the kitchen. | The fire did not start in the kitchen. | No | No |
| The dam failed because of the flood. | The dam failed because of poor maintenance. | Yes | Yes |
| At least one inverter at the farm failed. | Not every inverter at the farm failed. | Yes | No |

Answer the two truth questions **for every pair**, even when you answered "Not linked".

## Part 2: claims as stated

For each numbered claim: **does the response assert it as written?**

- **Asserted as written:** the response says this, in any wording.
- **Changed or contradicted:** the response states something related but different: a
  different number, date or name, the opposite, or a claim it then says is false.
- **Not stated:** the response does not say this at all.

Judge only what the text says. **Some claims are false in the real world, on purpose.**
If the response states a false claim, it is "asserted as written". Do not mark a claim
down because you believe it is wrong.

## Part 3: edited versions

Each version is the response you read with a change. **Removed text is struck through in
red. Added text is marked in blue.** Everything else is unchanged.

**Compared with the response you read, is this version more coherent, about as
coherent, or less coherent?**

A response is coherent when the things it says can all be true together, and the
connections it draws between them hold up. Ask: if I believed everything this version
says, would I be believing something consistent?

**Did the change alter anything besides a link between claims?** Most edits add, remove
or change one connection. If the change also altered a fact, a number, what a claim
means, or another connection, choose **minor** or **material** and quote the text in the
box.

Some versions may make no change at all. Answer those honestly.

## What is not the target

Do **not** reward length, fluency, style, vocabulary, or whether the claims are true in
the real world. Judge only whether the response holds together.

## Practical notes

- Every answer is required. Label Studio will not let you submit with a gap.
- You cannot go back to a task after submitting it, so finish each one before moving on.
- If a task is confusing, answer as best you can and write a note in any text box. Do
  not skip it.
- Please do not discuss the tasks with other annotators until everyone has finished.
