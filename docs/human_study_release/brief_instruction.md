# Annotator brief: comparison session

Thank you for taking part. This session takes **about 2 hours 50 minutes**, and never
more than 3 hours. Take a 10-minute break about halfway through. Please read this whole
brief before you start.

## What you will do

Each screen shows **two responses, A and B**, answering the same question. They contain
much the same content. You will see 21 screens, plus 3 practice screens first.

Above the two responses is **a question**, highlighted in blue. **The question is not the
same on every screen.** Read it each time, and answer exactly the question asked.

There are two kinds of question:

- One asks which response **would leave you believing something consistent**, if you
  believed everything it says. This is about whether the claims fit together, not about
  how the response reads.
- The other asks which response **hangs together better as an argument**. This is about
  the response as a piece of writing.

These can have different answers for the same pair. That is expected, and it is what the
study is measuring. Please don't try to give the same answer under both.

## Your answer

- **Response A** or **Response B**, if one is clearly better on the question asked.
- **About equal**, if you cannot tell them apart on that question.

"About equal" is a real answer. Use it whenever it is honest.

Then give your **confidence** (low, medium or high; low is fine) and **one sentence**
saying why. For example: *"B refers to 'that deficit' before any deficit has been
mentioned."*

## What is not the target

Do not reward length, vocabulary, or whether the claims are true in the real world. You
do not need any outside knowledge, and you should not look anything up.

## Practical notes

- Every choice is required.
- You cannot go back to a screen after submitting it.
- Please do not discuss the screens with other annotators until everyone has finished.
