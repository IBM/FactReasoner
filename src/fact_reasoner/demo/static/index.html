How it works

Logical Coherence Score, from FactReasoner

Close

Factuality asks whether each claim is supported by evidence. Coherence asks whether the claims hang together. A response can be fully factual and still contradict itself.

  1. Claims. The response is split into atomic claims. Each is matched back to the words in the text that state it.
  2. Relations. The selected RITS model reads each pair of claims against the response. It names the discourse sense (Evidence, Contrast, Cause–Effect, …), which compiles to a logical coupling, and estimates how strongly the response draws the link.
  3. Model. Every claim becomes a binary variable with a prior. Every relation becomes a pairwise factor whose weight is the mined strength p. Merlin solves the resulting Markov random field.
  4. Scores. The scores are read off that one model: the mean posterior, the probability that no relation is violated, and the normalized log partition.

The posteriors can be compared with the priors. A claim pulled below its own prior is one the response's own argument undermines. No aggregate score shows this.

With factuality priors, FactReasoner first retrieves evidence for each claim. Its posteriors then seed the coherence model, so the score reflects both questions.
