How it works

Factuality and logical coherence, from FactReasoner

Close

Two questions about one response. Factuality: is each claim supported by evidence? Coherence: do the claims hang together? A response can be fully factual and still contradict itself, or perfectly consistent and wrong.

  1. Claims. The response is split into atomic claims. Each is matched back to the words in the text that state it. Both analyses use the same claims.
  2. Factuality. FactReasoner gathers evidence for each claim (web search, Wikipedia, or passages you paste), asks whether each passage supports or contradicts the claim, and solves a graphical model for the probability that each claim is true. Its model extracts the claims; on Ollama the support question goes to the kev decision model, which returns a probability for each verdict in one pass.
  3. Coherence. The relation miner's model reads each pair of claims against the response and names the discourse relation (Evidence, Contrast, Cause–Effect, …), which compiles to a logical coupling with a strength p. A Markov random field over the claims gives the coherence scores.
  4. Both. The factuality posteriors become the coherence model's priors, so one score reflects both questions.

A claim pulled below its own prior is one the response's own argument undermines. No aggregate score shows this.
